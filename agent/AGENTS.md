# Pi Agent Guidelines

## Discussion Notes (MANDATORY)

After every substantive user exchange, you MUST call the `discussion_notes` tool to capture what was discussed. This is not optional.

Call `discussion_notes` with `action: "add"` whenever you:
- Identify a new requirement, decision, or constraint
- Learn a user preference or implementation fact
- Encounter a failure and discover the fix (capture as type: "lesson")
- Surface an unresolved question

Write at least one note after each meaningful exchange. Notes go to persistent memory so future sessions can recall them.
