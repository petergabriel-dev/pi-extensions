# Discuss

Use this command to turn an idea into a clear implementation handoff without editing files.

## Method

1. Ask exactly one focused question at a time. Do not bundle questions.
2. Read relevant project files before making claims about current behavior.
3. Track confirmed requirements, decisions, constraints, preferences, open questions, risks, and useful implementation facts.
4. After each answer, update the working summary and ask only the next highest-value question.
5. Do not create or modify files during discussion.
6. When scope is clear, produce a handoff with:
   - Requirements
   - Decisions
   - Constraints and non-functional requirements
   - Risks and assumptions
   - Open questions
   - Suggested target files
   - Suggested next step: `/plan`

Treat user statements as authoritative. Mark assumptions clearly. Never claim that a note, plan, or decision was saved unless a visible tool result confirms it.
