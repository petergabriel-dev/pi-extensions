## Conventions

- **TUI surfaces use live command/session context.** Use `ctx.ui` for status/widget UI and gate those calls with `ctx.hasUI`; persistent-memory follows this for memory meter updates ([index.ts#L123-L124](file:///Users/petergabrielrlopez/.pi/agent/extensions/persistent-memory/index.ts#L123-L124), [index.ts#L928-L929](file:///Users/petergabrielrlopez/.pi/agent/extensions/persistent-memory/index.ts#L928-L929)). Do not use host `pi.ui` for `setStatus`/`setWidget`.
- **Detached UI work captures a live context at trigger time and clears it in `finally`.** Subagent progress keeps a current context for scheduled redraws and drops stale contexts on render failure ([progress.ts#L22-L55](file:///Users/petergabrielrlopez/.pi/agent/extensions/subagents/progress.ts#L22-L55)); persistent-memory uses `currentMemoryMeterCtx = ctx.hasUI ? ctx : undefined` when background reconciliation starts and clears it in the task `finally` ([index.ts#L360-L364](file:///Users/petergabrielrlopez/.pi/agent/extensions/persistent-memory/index.ts#L360-L364), [index.ts#L435-L437](file:///Users/petergabrielrlopez/.pi/agent/extensions/persistent-memory/index.ts#L435-L437)).
